# Buyer Personas — EWAO Internacional

> Documento compartido entre todos los grupos. El Grupo 1 lidera su definición; todos los grupos aportan desde su especialización.

---

## Buyer personas prioritarios

### 1. Turista de experiencia Waorani

| Dimensión | Descripción |
|-----------|-------------|
| **Nombre** | Turista consciente / viajero de experiencia |
| **Edad** | 28-45 años |
| **Ingresos** | Medio-alto a alto |
| **Ubicación** | Europa (Alemania, Francia, Países Bajos), Norteamérica, Latinoamérica urbana |
| **Motivación** | Experiencia auténtica, conexión con naturaleza, turismo regenerativo, fotografía |
| **Barrera** | Precio, seguridad, logística, greenwashing percibido |
| **Canal de descubrimiento** | Instagram, Google, recomendaciones, artículos de viaje |
| **Disposición a pagar** | Media-alta (premium si la experiencia se percibe como única) |
| **Principio crítico** | No es caridad — es turismo profesional con guías indígenas |

### 2. Voluntario universitario / profesional

| Dimensión | Descripción |
|-----------|-------------|
| **Nombre** | Voluntario de habilidades |
| **Edad** | 20-35 años |
| **Perfil** | Universitario o profesional temprano en salud, ingeniería, comunicación, biología |
| **Motivación** | Aportar habilidades reales, CV internacional, experiencia transformadora |
| **Barrera** | Costo, tiempo, miedo a la "voluntourism" (asistencialismo) |
| **Canal de descubrimiento** | Universidades, LinkedIn, redes de voluntariado, recomendaciones |
| **Disposición a pagar** | Media (paga estancia + operación, no dona) |
| **Principio crítico** | Colaboración, no asistencia — el voluntario aporta una habilidad específica |

### 3. Comprador de artesanía WEMA

| Dimensión | Descripción |
|-----------|-------------|
| **Nombre** | Consumidor de comercio justo / decorador consciente |
| **Edad** | 30-55 años |
| **Perfil** | Interesado en diseño, artesanía única, sostenibilidad, decoración con historia |
| **Motivación** | Piezas únicas con trazabilidad, historia de la artesana, impacto social |
| **Barrera** | Disponibilidad, precio premium, envío internacional, confianza en origen |
| **Canal de descubrimiento** | Instagram, marketplaces de comercio justo, diseñadores, museos |
| **Disposición a pagar** | Alta (si el storytelling y trazabilidad son creíbles) |
| **Principio crítico** | Valor percibido sin industrializar la tradición cultural |

### 4. Empresa B2B ESG / partnership

| Dimensión | Descripción |
|-----------|-------------|
| **Nombre** | Partner corporativo |
| **Tipo** | Empresas con programas ESG, certificación B Corp, retail sostenible, turismo |
| **Motivación** | Alianza reputacional, impacto medible, contenido auténtico, RSE |
| **Barrera** | Escalabilidad, medición de impacto, coherencia de marca |
| **Canal de descubrimiento** | LinkedIn, eventos de sostenibilidad, directorios ESG, prensa |
| **Modelo** | Partnership B2B, licencia, patrocinio, compra directa |
| **Principio crítico** | Comunicar solo lo demostrable — el partnership no es greenwashing |

### 5. Donante / financiador

| Dimensión | Descripción |
|-----------|-------------|
| **Nombre** | Donante internacional |
| **Tipo** | Persona de alto patrimonio, fundación, agencia de cooperación, universidad |
| **Motivación** | Impacto real y medible, transparencia, sostenibilidad a largo plazo |
| **Barrera** | Confianza en la organización, trazabilidad del dinero, resultados |
| **Canal de descubrimiento** | Redes de filantropía, referencias, eventos, artículos de impacto |
| **Disposición a pagar** | Variable (donación recurrente, crowdfunding, grant) |
| **Principio crítico** | Mostrar solo lo demostrable; nada de asistencialismo en la narrativa |

### 6. Investigador / universidad

| Dimensión | Descripción |
|-----------|-------------|
| **Nombre** | Partner académico |
| **Perfil** | Investigador, programa universidad, ONG de investigación |
| **Motivación** | Datos de campo, biodiversidad, estudios culturales, oportunidad de publicación |
| **Barrera** | Acceso al territorio, permisos, relación con comunidad |
| **Canal de descubrimiento** | Publicaciones académicas, conferencias, alianzas entre universidades |
| **Principio crítico** | La comunidad decide qué investigar y qué publicar; los datos son de ellos |

### 7. Medio de comunicación / prensa

| Dimensión | Descripción |
|-----------|-------------|
| **Nombre** | Periodista / medio internacional |
| **Tipo** | Prensa especializada (turismo, sostenibilidad, cultura, derechos indígenas) |
| **Motivación** | Historia única, ángulo diferenciado, contenido visual potente |
| **Barrera** | Acceso, claridad del mensaje, riesgo de estereotipos |
| **Principio crítico** | Narrativa desde el territorio; no desde la mirada externa |

### 8. Comunidad interna Waorani

| Dimensión | Descripción |
|-----------|-------------|
| **Nombre** | Comunidad Keweriono |
| **Idioma** | Wao Tededo, español (según generación y ubicación) |
| **Acceso** | Conectividad variable, dispositivos móviles predominantes |
| **Necesidad** | Información de proyectos, mecanismos de consulta, devolución de resultados |
| **Canal** | WhatsApp, audio, video, reuniones comunitarias |
| **Principio crítico** | La internacionalización empieza por casa; la comunidad es socia, no audiencia |

## Posicionamiento cultural (GCCP / FCCP / LCCP)

| Buyer Persona | Estrategia | Justificación |
|---------------|------------|---------------|
| Turista consciente | **GCCP** | Cultura global del viajero consciente; adaptación local del territorio |
| Voluntario universitario | **GCCP** | Cultura global del voluntariado profesional; adaptación local a territorio Waorani |
| Comprador WEMA | **FCCP** | Atractivo de lo foráneo auténtico; la cultura Waorani es el valor diferencial |
| Empresa B2B | **GCCP** | Cultura global del ESG corporativo; adaptación al contexto amazónico |
| Donante internacional | **GCCP** | Cultura global de filantropía de impacto; adaptación local |
| Investigador | **FCCP / GCCP** | Mezcla — cultura académica global + valor del conocimiento local |
| Prensa | **FCCP** | Lo foráneo y auténtico es lo que hace la historia noticiable |
| Comunidad Waorani | **LCCP** | Local primero — contenido en Wao Tededo, español, formatos accesibles |

## Cómo usar este documento

1. Cada grupo profundiza las buyer personas relevantes a su área en su carpeta de entregables
2. El Grupo 1 coordina la versión canónica y resuelve conflictos entre grupos
3. Cualquier nueva buyer persona propuesta debe pasar por el Grupo 1 para mantener coherencia
4. Actualizar la tabla de posicionamiento cultural conforme avancen los capítulos
